## CDP 端到端回归

[`tools/cdp-test.mjs`](../tools/cdp-test.mjs) 通过 Chrome DevTools Protocol（`http://127.0.0.1:9222`）连接运行中的应用，逐项断言核心链路（第三期 **23 项**，含 88 键 / 顶栏按钮 / 音区偏移 / F 键无动作）：

| # | 断言项 |
|---|---|
| 1 | 就绪界面出现（`.stage.show`），加载层隐藏 |
| 2 | 内置儿歌共 10 首 |
| 3 | 状态条就绪提示 |
| 4 | F1~F12 按下无动作（不切模式 / 不触发功能） |
| 5 | 「🎵 儿歌」按钮打开面板 |
| 6 | 儿歌播放状态显示（「▶ 播放」） |
| 7 | 录音开始状态（「● 录音」） |
| 8 | 录音停止并保存（「■ 停止」） |
| 9 | 回放触发（「▶ 回放」，状态条提示） |
| 10 | 录音列表持久化 ≥1 条 |
| 11 | 无渲染层 JS 错误 |
| 12 | 音量调整生效（「音量 +」） |
| 13 | Escape 关闭全部面板 |
| 14 | 布局虚拟键盘 **88 键**（A0–C8，21~108） |
| 15 | 模式 chips 点击切换四模式（弹奏→欣赏→练谱→挑战→弹奏） |
| 16 | 音区按钮 ±1 八度（「音区 + / −」） |
| 17 | 弹奏模式音名气泡 |
| 18 | 中央 C 徽标 |
| 19 | 字幕带 DOM 存在 |
| 20 | 欣赏模式瀑布方块 |
| 21 | 字幕带简谱序列 |
| 22 | 欣赏播放点亮虚拟键 |
| 23 | 视觉层交互后无 JS 错误 |

其余关键链路（儿歌打断、录音互斥等）见脚本。

### 运行方式

```bash
# 终端 A：启动应用（开发或打包版均可）
npm run dev -- --remote-debugging-port=9222

# 终端 B：跑回归
node tools/cdp-test.mjs
```

**注意**：测试脚本默认连接 `127.0.0.1:9222`；如端口占用或 CDP 未开启，脚本会报连接失败。日志中出现 `DevTools listening on ws://127.0.0.1:9222` 即就绪。

## 打包版回归

打包后的应用走 `app.isPackaged` 分支（采样路径、日志、userData 均不同），**必须**单独回归：

```bash
# 1) 启动打包版（带 CDP）
dist\win-unpacked\键盘模拟钢琴.exe --remote-debugging-port=9222

# 2) 另开终端跑同一套回归
node tools/cdp-test.mjs
```

重点人工核验（主进程行为，脚本难覆盖）：

- [ ] Kiosk 全屏：无边框、无任务栏图标、置顶
- [ ] 防退出：`Ctrl+Alt+Shift+Q` 弹出确认面板；「取消」不退出
- [ ] 关闭窗口（Alt+F4 / 标题栏关闭）被拦截，仅确认后退出
- [ ] 录音持久化：重启应用后「我的录音」列表仍存在
- [ ] MIDI 导出：另存对话框可写 `.mid`，可被其他播放器打开

## 故障排查速查

| 症状 | 原因 / 解法 |
|---|---|
| 采样 404、`#` 被截断 | FLAC URL 中 `#` 必须 `%23` 编码 |
| 加载 0/90 卡住 | 采样目录缺失 → 先跑 `download-samples.mjs`，目录为空 |
| `fetch` 失败 | file:// 协议下用 **XHR**，不要用 fetch |
| 打包报《ECONNREFUSED 127.0.0.1:443》 | 见 [📦 build.md](build.md#打包二进制下载排障) |
| 打包版无声 | 检查 `resources/samples` 是否外置完整（90 FLAC） |
| 二开后退出 | 单实例锁：重复启动仅聚焦原窗口，勿开多实例 |
