## 🔑 核心约定（实现勿偏离）

1. **防退出组合键固定 `Ctrl+Alt+Shift+Q`**（主进程 globalShortcut；渲染层收不到该组合，天然不发声）
2. **全键盘发声**：除方向/编辑功能键、修饰键、Win、PrintScreen/媒体键外，其余物理键全部映射音符；**F 行（F1~F12）第三期起映射 `none`**（功能改顶栏按钮）
3. **Win 键系统级屏蔽**：主进程低级键盘钩子（`@fainthit/uiohook-napi-suppress`）吞掉 Win 键本体及 Win+任意组合，开始菜单永不弹出（儿童乱按不丢声音）
4. **Node 集成关闭**：渲染层一律走 preload `/window.pianoAPI` 桥（contextIsolation + sandbox）
5. **统一事件管线**：录制 / 回放 / 儿歌共用 `{a:'down'|'up', n:midi, v:velocity, t:秒}` 事件序列
6. **本地持久化**：落盘在 `app.getPath('userData')`，录音保留最近 10 条
7. **采样不进 asar**：超大 FLAC 经 `extraResources` 外置，渲染层经 IPC 拿到 `file://` 绝对路径
8. **模式切换**：顶栏模式 chips 点击：弹奏 → 欣赏 → 练谱 → 挑战（仅虚拟键盘，无鼠标/触摸弹琴）
9. **视觉层纯订阅**：四模式/字幕带/卷帘不修改发声、录音、儿歌逻辑，只消费事件总线
10. **动效统一 rAF 时钟**：回放/判定/字幕/瀑布/卷帘共用同一时间基准，杜绝 setTimeout 漂移
